## 🛠️ Stack Technique

- **Frontend & Rendu** : HTML5 sémantique, Tailwind CSS, JavaScript ES6+, Canvas API.
- **Icônes & Typographie** : Lucide Icons, Plus Jakarta Sans, JetBrains Mono.
- **Audio** : Web Audio API pour les micro-interactions sonores (activables/désactivables).
- **Déploiement** : Prêt pour un déploiement instantané sur [Vercel](https://vercel.com) (fichier `vercel.json` inclus).


## 📷 Personnalisation des Images et Coordonnées

- **Photo de profil** : Déposez votre photo dans le dossier `assets/` (ex: `assets/ma-photo.jpg`) et mettez à jour `avatarUrl` dans `js/data.js`.
- **Captures réelles FIARAmotion** : Déposez vos captures d'écran dans `assets/` et actualisez le tableau `gallery` dans `js/data.js`.
- **E-mail de contact** : Personnalisez `profile.email` dans `js/data.js`.
